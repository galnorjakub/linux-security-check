# Linux-Security-Check

## Objective

The Linux Security Check project aimed to gather essential informations about the system, such as user, hostname, OS/Kernel information, storage and memory usage, network informations, currently logged users, and root detection.

### Skills Learned

- Navigation inside of the Linux system
- Creating a bash script
- Gathering informations about the system using Linux commands
- Basic reconnaissance

### Tools Used
pwd
cd
mkdir
touch/nano
date
whoami
hostname
hostnamectl
df -h
free -h
ip -br addr
who
wc -l < /etc/passwd
